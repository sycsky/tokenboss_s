# 服务暂停公告与前端入口收敛

状态：用户已确认第二版原型，并明确本次仅修改前端；本地实施与验证完成，未部署。

## Why

据用户说明，当前服务器供应商将在 12 月关闭服务器。TokenBoss 计划暂停服务，但保留网站与退款联系渠道，并另行迁移网站。

## What Changes

- 首页与其他页面顶部公告：2026 年 12 月 1 日 00:00（北京时间）暂停服务。
- 退款邮箱 `shawn@tokenboss.co`；请申请人提供登录邮箱与联系微信。
- 网站隐藏注册、登录、充值、购买、续费、兑换等业务入口，原位置可统一展示“停服说明”。
- 直接访问旧注册、登录、验证、OAuth 回调、充值及付款页面时显示公开说明，不展示相应表单。
- 说明页与退款政策、页脚保持一致；停服日期只驱动前端文案时态。
- 首页仅保留顶部公告，不加入 slogan 旁的状态卡片或重复停服段落。

## 范围修正

用户在实施中明确：“这次变动的只有前端……充值……只要把入口隐藏掉就好”。本决定取代此前的后端关闭与 API 截止方案。已撤回本轮后端 handler/core/test/config 修改；不更改后端认证、支付、Agent skill 或模型调用，不自动停止已有 API Key。

## 分期与边界

本次只完成前端可审阅代码；不部署、不变更 DNS、不执行数据迁移或退款。新托管位置、实际服务关闭、数据备份与邮箱收信验证另行处理。网站公告不能作为后端 API 已被禁用的证明。
