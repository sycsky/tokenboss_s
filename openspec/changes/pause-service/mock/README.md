# 停服提示交互原型

入口：`index.html`。自包含 HTML/CSS/JavaScript，不加载第三方字体、脚本或业务 API，可直接打开，或使用静态 HTTP 服务预览。

预览工具栏支持四个页面、桌面/手机以及停服前/停服后。邮件按钮唤起邮件客户端，不发送邮件；复制按钮需要宿主允许剪贴板写入。

## 本轮验证

2026-11-04 使用 Ego Browser 在真实 Chromium 页面核验：

- 375、390、768、1440px 四种视口下分别切换首页、说明页、套餐入口、退款政策，共 16 种组合；document 与原型容器均未发现横向溢出。
- 导航登录入口进入说明页，出现“登录功能已关闭”上下文，页面无登录表单或输入框。
- 邮件链接收件人为 `shawn@tokenboss.co`，预填主题与“TokenBoss 登录邮箱、联系微信”标签；未唤起或发送真实邮件。
- 停服后公告使用“已于”表述，说明页不再包含“可在停服前”继续使用的提示。
- 视觉查看桌面首页、桌面说明页及手机说明页；修正手机公告中北京时间标签被拆开的问题。

限制：未对用户剪贴板做写入测试，未验证实际收信，未测试正式网站/API。原型顶部工具栏仅供审阅，不进入生产页面。

## 用户审阅后的修订

撤掉首页新增的服务状态卡片与 slogan 下方重复的停服段落；首页顶部公告保留。原登录、注册、充值按钮统一为“停服说明”，跳转完整说明页。此修订取代最初原型中的右侧状态卡片建议。
