# 停服提示：位置、文案与样式提案

状态：2026-11-04 用户已认可后端规则及本文件的前台位置、样式方向；第二版原型已确认，正在实施；用户最新限定仅改前端，隐藏入口即可。尚未部署。

## 目标与方向

保留现有网站，通过三层信息让用户了解停服安排：顶部短公告、完整说明页、页脚退款联系。沿用现有视觉，不重新设计网站。

**当前范围：仅前端隐藏/替换入口，后端认证、支付和 API Key 保持原样。** 文案中的“关闭”指网站入口，停服日期仅控制前端展示。

用户在查看原型后的最新修正：首页有顶部公告即可，移除 slogan 旁新增的服务状态卡片与重复停服说明；其他操作入口统一使用“停服说明”。此修正优先于此前保留“登录”文字的提案。

建议用一个可分享的说明页 `/service-notice` 承接登录、注册、充值等入口。首页顶栏先让用户看到时间；说明页承载完整文案和退款指引。相较弹窗，独立页面更适合旧链接直达、刷新、移动端阅读，以及旧后端关闭后独立保留。

## 提示位置与交互

| 位置 | 显示什么 | 点击或访问后的行为 |
|---|---|---|
| 首页最顶部，导航栏上方 | 完整停服时间；注册、登录及新增充值已关闭；退款邮箱；“查看详情” | 查看详情进入 `/service-notice`；邮箱为邮件链接并可选中复制 |
| 其他页面最顶部，包括 Primitives、套餐、接入文档、政策页及既有会话的控制台 | 同样的时间与状态，使用紧凑版，保留“退款说明”链接 | 进入同一说明页；不依赖登录态或后端响应 |
| 原导航“登录”、首页“已有账户？登录”入口 | 统一改为“停服说明”；同一区域避免重复放相同链接 | 点击进入说明页，不出现原登录表单；直接访问旧登录、注册、验证及 OAuth 回调链接也展示说明 |
| 首页与套餐中的“免费开始”“立即充值”“开通”等按钮 | 改为“停服说明”；试用赠额标签与鼓励新付费的引导同步撤下 | 点击进入说明页；套餐资料可以保留，卡片标记“已停止销售”，不再显示可购买状态 |
| 充值、付款页及既有会话控制台中的充值入口 | 原充值按钮改为“停服说明”；直达充值/付款页显示说明 | 不展示支付方式、金额输入、付款码或新收银台链接；已有订单详情继续按后端规则保留 |
| 接入页 | 顶部公告；原注册登录、创建新接入流程的位置改为说明入口 | 已有 API Key 的配置文档在截止前可阅读；不引导创建新账号或充值；到期后明确已停服 |
| 页脚 | “停服说明”链接以及 `shawn@tokenboss.co` | 进入说明页或唤起邮件客户端；移动端同样可见 |
| 退款政策页 `/refund` | 原政策正文前增加“本次服务暂停的退款申请”说明 | 展示同一邮箱与需要提供的两项信息，避免被旧“不支持退款”文字否定 |

既有有效会话的账户、余额、用量和订单查看能力按后端规则保留；控制台顶部同样展示公告。未登录用户点击控制台仍落到停服说明，而非出现可登录表单。

## 视觉规格（提案）

### 顶部公告条

- 布局：横跨页面，位于导航上方；内容最大宽度约 1200px，与现有页面对齐。
- 背景：浅黄 `#FEF3C7`；文字：现有深色 `#1C1917`；底部 2px 深色边框。
- 左侧小标签“服务暂停公告”，正文 14px，日期加粗；链接使用下划线，字号不小于正文。
- 桌面端约两行，移动端自然分为三至四行，不截断时间或邮箱，不横向滚动。
- 随页面正常滚动；不可关闭，不使用倒计时或入场动画。公告应在首次打开时直接可见。
- 首页在短公告中直接显示邮箱；其他页面用时间、当前状态和说明链接压缩内容。

### 完整说明页

- 复用现有品牌 Logo、米白背景 `#F7F3EE`、白色卡片、2px 深色边框、4px 硬阴影和 6–8px 小圆角。
- 内容最大宽度约 640px；手机左右留白 20px，无表单、无登录按钮。
- 页面标题“服务暂停与退款说明”，桌面 32px、手机 26px；正文 15px，行高约 1.7。
- 浅黄时间区域突出“2026 年 12 月 16 日 00:00 / 北京时间”。
- 正文按顺序呈现：停服时间 → 当前已关闭的功能与已有 Key 安排 → 退款联系。
- 退款区域独立白色描边卡片，邮箱 20px 加粗；列出“TokenBoss 登录邮箱”“联系微信”。
- 主按钮“发送退款申请邮件”，使用现有橙色 `#E8692A` 和深色描边；次按钮“复制邮箱”；下方提供“返回首页”。
- 邮件主题可预填“TokenBoss 退款申请”，邮件正文可预填两项标签，由用户自行填写并发送；按钮点击本身不代表已提交申请。
- 复制成功后按钮短暂显示“已复制”；复制不可用时，邮箱仍可手动选中，不要求用户安装邮件客户端才能获得联系地址。

### 页脚及政策补充

- 页脚沿用深色背景，以白色/浅色文本展示邮件链接；不另加弹层。
- 退款政策中的专项说明使用同一浅黄色提示块，放在旧常规条款之前。
