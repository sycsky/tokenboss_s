# 服务暂停、公告与退款联系入口

状态：用户已确认停服时间、退款邮箱、第二版原型；最新范围仅限前端，本地实施与验证完成。
来源：2026-11-04 当前会话及用户后续范围修正。

## 问题

据用户说明，服务器供应商将在 12 月停机；TokenBoss 希望暂停服务，同时保留网站供用户查看公告与退款联系方式。

## 期望结果

1. 首页顶部公告：2026 年 12 月 1 日 00:00（北京时间）暂停服务。
2. 网站不再提供注册、登录、充值等入口，原按钮可写“停服说明”；直接访问旧业务页面同样展示说明。
3. 有退款需求的用户向 `shawn@tokenboss.co` 提供 TokenBoss 登录邮箱与联系微信，后续人工核实处理。
4. 首页仅需顶部公告，移除原型新增的 slogan 旁状态卡片及重复停服段落。
5. 网站后续迁移，在旧服务器关闭后继续保留公告与联系方式。

## 涉及用户与系统

访客、已有用户、有退款需求的用户与运营；本次交付仅涉及网站前端。

## 约束

- 本轮用户要求发布前提前公告日期；采用其第一个选项：2026 年 12 月 1 日 00:00（北京时间），即 11 月 30 日结束时。它与“11 月最后一天 00:00”相差一天，实施时已向用户明确采用前者。

- 最新用户指示明确只改前端，以隐藏入口和显示说明为准；此前后端拦截、定时停止 API 的方案已被此指示替代。
- 不修改后端认证、支付、已有 API Key 或 Agent skill，不自动关闭模型调用。
- 公告时间固定为 `2026-12-01T00:00:00+08:00`；日期切换只影响前端展示。
- 退款无需登录；不承诺退款资格、金额、到账时限或自动退款。
- 暂停登录仅指本次前端入口行为，不宣称后端接口已经关闭。

## 开放问题

迁移阶段另行核实：供应商实际停机时间、新托管与 DNS 权限、旧链接落点、退款所需 TokenBoss/newapi 数据备份读取验证、`shawn@tokenboss.co` 持续收信能力。

## 设计参考

现有 `/register` 是 `/login` 别名；登录支持验证码和 GitHub OAuth。前端改为公开说明页，无需后端加载成功。已有会话不主动注销；账户、余额、用量和订单查看保留，充值等入口隐藏或替换。旧后端不受本次改动限制。
